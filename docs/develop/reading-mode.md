# 章节阅读模式

在章节编辑工具栏点击书本图标「阅读模式」即可进入只读阅读界面。手机在键盘收起时也会显示入口。阅读界面使用当前编辑草稿，其他章节会优先显示有效的本地工作副本。退出后回到原编辑章节，保留编辑内容、位置与键盘焦点。

默认使用 `←` / `↑` 上一页、`→` / `↓` 下一页，也可以点击底部按钮。按当前视口高度翻页，并保留少量上下文重叠以避免截断行丢失。章节末页继续向后会按分卷和章节顺序进入下一章；章节首页向前则进入上一章末页。短章节和空章节均占一页。

「阅读设置」支持自定义上一页、下一页的单键快捷键；两者不能冲突。默认自动翻页间隔为 10 秒，可设置为 1–3600 的整数秒。偏好保存在当前浏览器或桌面实例的本地数据库。自动翻页需要手动点击「开始自动翻页」，重新进入阅读模式不会自动播放。

打开设置、手动翻页、窗口失焦、切换到后台、章节加载失败或读到最后一页时，自动翻页会暂停。跨章加载期间计时暂停，成功加载后重新计时；失败时保留原章节供继续阅读和重试。退出时会清理计时器，迟到的加载结果不会重新打开阅读模式。

`Esc` 先关闭阅读设置，再次按下退出阅读模式。输入框内、输入法组合输入期间及带 Ctrl/Alt/Meta 的组合键不会触发翻页。阅读界面的快捷键不会覆盖正常编辑时的方向键。

Android 客户端支持音量键：音量＋上一页，音量－下一页，长按仅翻一页。只在阅读界面可操作且应用处于前台时拦截；打开阅读设置、加载章节、窗口失焦或退出阅读后恢复系统音量行为。音量键翻页与自定义键盘按键相互独立，手动翻页同样会暂停自动播放。需要安装包含此原生桥接的新客户端，手机浏览器/PWA 不能通过网页代码获得同样的系统音量键能力。

原生使用受实例来源和主框架限制的 `OpenFicReading` WebView 消息通道，并在导航、生命周期变化后重置和重新同步捕获状态。7 项 Kotlin/JUnit 按键策略测试覆盖按下/抬起、长按、退出与状态切换；阅读模式浏览器回归扩展至 22 项，覆盖桥接启停及没有原生通道时的行为。浏览器模拟消息测试不等同于手机物理按键实测。

验证覆盖分页边界、快捷键与偏好校验的 11 项 Node 测试，以及桌面/手机、未保存草稿、自动衔接、加载失败、窗口尺寸变化、焦点恢复和音量键桥接的 26 项 Chrome 浏览器回归。前端脚本套件、TypeScript、类型感知 lint 和生产构建均通过。

cd frontend

Android 工程需要 Java 21、Android SDK 35 和 Build Tools 35.0.0。先在 `mobile` 执行 `pnpm sync` 同步最新页面，再在 `mobile/android` 执行 `gradlew testDebugUnitTest assembleDebug`。
